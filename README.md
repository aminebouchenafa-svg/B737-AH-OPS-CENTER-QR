# B737 OPS Center

Outil de référence rapide pour les équipages B737 — numérisation de l'Ops Info, installable sur iPad/iPhone et utilisable hors connexion.

## 🔗 Lien de l'application

**https://aminebouchenafa-svg.github.io/B737-AH-OPS-CENTER-QR/**

## Installation (iPad / iPhone)

1. Ouvrir le lien ci-dessus dans **Safari** (obligatoire, les autres navigateurs ne permettent pas l'installation sur iOS).
2. Appuyer sur l'icône **Partager**.
3. Faire défiler et appuyer sur **« Sur l'écran d'accueil »**.
4. Confirmer le nom et appuyer sur **Ajouter**.

L'application fonctionne ensuite comme une app native, y compris sans connexion.

## Contenu

RNP, LVP (CAT II/IIIA), CPDLC, procédures par temps froid, GRF/RCAM, BRNAV/PRNAV, contacts compagnie, codes retard IATA, et un bloc-notes de vol.

## Accès

L'application est protégée par un identifiant/mot de passe commun, réservé au personnel navigant technique de la compagnie.

## ⚠️ Avertissement

Outil non officiel, à utiliser en complément — toujours vérifier les données avec le FCOM/OM-A/OPS INFO en vigueur.
